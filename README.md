# Deepak Soni Portfolio

Personal portfolio website for Deepak Soni, a Python and Django backend developer. The site presents his experience, technical skills, selected backend projects, and contact details in a responsive single-page layout.

## Features

- Responsive navigation with a mobile menu
- Light and dark theme toggle
- Hero, About, Skills, Experience, Projects, and Contact sections
- Scroll reveal animations
- Project links and social/contact call-to-actions
- Responsive styling for desktop, tablet, and mobile screens

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome icons
- Google Fonts

The portfolio content highlights Python, Django, Django REST Framework, Django Channels, Git, GitHub, and deployment platforms such as PythonAnywhere and Render.

## Project structure

```text
deepaksoni-portfolio/
├── one.html       # Main portfolio page
├── portfolio.css  # Layout, responsive styles, themes, and animations
├── script.js      # Menu, theme, scroll, and interactive behavior
└── README.md      # Project documentation
```

## Run locally

No build tools or dependencies are required.

1. Clone the repository:

	```bash
	git clone https://github.com/deepaksoni2206/deepaksoni-portfolio.git
	cd deepaksoni-portfolio
	```

2. Open `one.html` directly in a browser.

For a local development server, run one of these commands from the project folder:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

Then visit `http://localhost:8000` or the URL shown by the server.

## Customization

- Edit text, links, and section content in `one.html`.
- Update colors, spacing, themes, and responsive rules in `portfolio.css`.
- Update menu, theme, and animation behavior in `script.js`.
- Replace placeholder social and project URLs with the final links before deployment.
